# Codex 会话修复助手

本地网页工具，用于查找和检查报 `invalid_encrypted_content` 的 Codex 会话，预览清理范围，备份并同步历史索引。运行时只使用 Python 标准库，不调用模型、不上传聊天记录。

## 打开和使用

安装 Python 3.11 或更高版本后，在项目目录运行 `python app.py --open`。

Windows 也可以双击本目录的 `Launch.cmd`；运行 `InstallShortcut.ps1` 可创建桌面快捷方式。

1. 搜索会话 ID、粘贴 `codex resume …` 命令，或按标题、摘要、项目路径查找。
2. 选择会话，点击 **检查会话**。默认同时检查其子代理，包括下级子代理。
3. 查看历史分段、加密块数量、索引检查结果，勾选实际需要修复的会话。
4. 点击 **备份并清理**，完成后退出旧会话，再用页面给出的命令重新打开。

“存在加密内容”不等于“已经损坏”。正常回复也会产生密文，本工具无法离线验证服务端的加密密钥，仅对你选择的报错会话执行清理。

## 备份、回滚与中断恢复

- 每批操作先保存所有选中会话的原文件、修复副本、索引快照与文件校验信息。
- 选中的主会话和子代理一起持有写入锁，在同一 SQLite 事务中更新对应索引。
- 文件替换发生错误时，回滚已经替换的文件和未提交的索引。
- 在 **修复记录** 中可以导出 ZIP 备份，或点击 **回滚到清理前**。
- 如果清理后已经出现新消息，工具会阻止覆盖式回滚；备份仍然保留并可导出。
- 遇到断电或进程中断留下的未完成操作，记录页提供 **恢复清理前状态**。只有当前文件和索引能与已保存快照对应时才会恢复。

备份保存在当前 Codex 数据目录的 `backups_state/tool-…`。工具也能读取兼容的早期独立/分段修复备份。不自动删除备份。

## 支持的结构

- 独立会话、同一逻辑会话回滚形成的多段历史。
- 子代理树，以及父会话中转存的子代理加密消息。
- `guardian_history`、`replacement_history` 等嵌套历史中的已支持加密结构。
- 有原始可读历史副本的推理摘要会保留；已被明文摘要替代的旧加密压缩检查点可清理。

占用中的会话、其他会话共享的基础历史、尚未完整投影的索引、不连续的序号、当前仍依赖的纯加密压缩检查点和未知格式，会显示停止原因。工具不会强行处理或结束 Codex 进程。

## 数据与运行

- 默认会话目录：`%USERPROFILE%\.codex`。
- 工具自身日志与启动记录：`%LOCALAPPDATA%\CodexSessionRepair`。
- 服务仅监听 `127.0.0.1`，有请求来源、Host 和操作令牌检查。
- 页面右上角 **退出工具** 会停止后台服务；正在处理时禁止退出。
- 源码运行需要 Python 3.11 或更高版本。

指定其他目录或端口：

```powershell
python app.py --home "C:\path\to\.codex" --data-dir "C:\path\to\tool-state" --open
```

## 验证

```powershell
python -m unittest discover -s tests -v
node --check web/app.js
```

测试使用合成会话和独立数据目录，覆盖单文件及分段清理、主会话与子代理批量处理、回滚、中断恢复、写入占用、过期快照、备份路径验证和本地 HTTP 请求保护。`tests/run_demo.py` 可启动合成数据页面用于界面验证。
